## 二、世界架构：POV 自由探索

### 2.1 第一人称视角
- **相机**：`PointerLockControls`（Three.js）—— 鼠标控制视角，WASD 移动
- **视角高度**：模拟人眼高度（~1.6m），轻微呼吸/步伐晃动
- **交互手势**：靠近可交互物体/NPC 时，视线中央出现轻量引导

### 2.2 城市街区环境（V1 范围）
一条 **100m 法式街道** + 1 个可进入咖啡馆：
- 街道：石板路、行道树、路灯、长椅、露天座位
- 咖啡馆：柜台、座位区、菜单板、咖啡机
- 边界处理：街区尽头设"施工围栏"自然引导

### 2.3 环境细节
- **光照**：日出→正午→傍晚→深夜的连续光照变化
- **氛围音**：底层白噪音（街车声、远处人声、鸟鸣），进入咖啡馆后切换室内音景
- **天气**：V1 不实现，只做昼夜

### 2.4 性能约束（Web 端核心矛盾）
- **LOD（细节层次）**：远距离建筑用低精度盒子，近身切高模
- **视锥剔除**：相机看不到的不渲染
- **目标帧率**：桌面浏览器稳定 30+ fps

## 三、NPC 系统（V1）

### 3.1 三个核心 NPC

| NPC | 身份 | 位置 | 性格 | 语言能力 |
|-----|------|------|------|---------|
| 服务员 | 咖啡馆服务员 | 咖啡馆柜台 | 热情/忙碌 | 只会法语 |
| 行人 | 街上路人 | 沿路径走动 | 中性 | 只会法语 |
| 老人 | 街角长椅上的老人 | 街角长椅 | 友善 | 只会法语 |

### 3.2 NPC 行为（V1 三种基础）
1. **idle**：站着/坐着，有轻微动作（看手机、喝咖啡）
2. **walk**：沿预设路径走动
3. **interact**：与环境交互（开门、整理柜台）

### 3.3 NPC 对玩家反应（V1 基础）
- 你走得太近 → 侧身让路
- 你开口说话 → 根据性格自然回应
- 你盯着看太久 → 轻微反应

## 四、对话体验架构（V1）

### 4.1 对话模型
- **输入方式**：键盘输入（自由文本）
- **对话引擎**：LLM 驱动（可插拔网关）
- **对话触发**：靠近 NPC → NPC 主动招呼 → 玩家输入 → NPC 自然回应
- **对话内容**：取决于 NPC 身份和当前场景

### 4.2 对话流程（V1 咖啡馆示例）
```
玩家走进咖啡馆 → 走近柜台
        │
        ▼
服务员："Bonjour! Vous désirez?"
        │
        ▼
玩家输入："un café, s'il vous plaît"
        │
        ▼
服务员（LLM 生成）："Un café, bien sûr! Café crème ou café noir?"
        │
        ▼
玩家输入："noir, merci"
        │
        ▼
服务员："Très bien. Voilà! 3 euros 50."
        │
        ▼
对话自然结束，咖啡端来
```

### 4.3 对话的"世界性"
对话不是凭空发生的，它长在场景里：
- 在咖啡馆 → 对话围绕点单、座位展开
- 在街头 → 对话围绕闲聊、问路展开
- NPC 的回应受时间、天气、当前状态影响

## 五、AI 网关（V1 最小实现）

### 5.1 统一抽象
```
玩家输入 + NPC 身份 + 世界状态 ──► Prompt 组装器 ──► 统一接口 ──► 适配器层
                                                                        ├── Ollama（本地）
                                                                        ├── DeepSeek
                                                                        ├── OpenAI
                                                                        └── 未来任何
```

- 前端不碰 API Key，全走后端代理
- 流式响应（SSE），NPC 回话逐字生成
- 供应商适配器用接口抽象，切换只改配置

### 5.2 Prompt 组装器（V1）
```
你是 {NPC名字}，一个巴黎 {职业}。
你的性格是 {性格}。
你现在在 {位置}，当前时间是 {时间}。
你会说法语，但不会英语。
玩家是一个刚搬到巴黎的新居民，法语不太好。

说话要求：
- 自然、口语化
- 根据玩家的表达水平调整复杂度
- 如果听不懂就说"Je ne comprends pas"
- 不要主动教语法，你只是在过自己的生活
- 回应要简短自然，像真实对话
```

### 5.3 世界状态模块（V1 最小）
- 当前游戏内时间
- NPC 位置/状态
- 玩家当前位置
- 不需要持久存储（V1 无存档需求）

## 六、技术栈（V1）

| 层 | 选型 | 职责 |
|----|------|------|
| **游戏引擎** | **Godot 4.x** | 场景搭建、渲染、物理、动画、Web 导出 |
| **3D 资产** | **Blender** | 建筑、家具、NPC 模型制作 |
| **脚本语言** | **GDScript** | 游戏逻辑、NPC 行为、对话触发 |
| **对话系统** | **HTTP 请求 + LLM API** | NPC 自由对话（可插拔） |
| **后端** | Node.js + Fastify | AI 网关、Prompt 组装、世界状态 API |
| **Web 导出** | Godot HTML5/WebGL | 浏览器可运行 |
| **Desktop 导出** | Godot Linux/Windows/macOS | 原生桌面版 |

**V1 不引入：**
- 语音模块（纯键盘）
- 天气系统
- 多人联网

## 九、执行路线（V1）

```
Phase 0   环境搭建
          ├── 安装 Godot 4.x（Linux AppImage）
          ├── 安装 Blender（Linux）
          ├── 学习 Godot 基础操作
          └── 创建 Godot 项目

Phase 1   资产制作（Blender）
          ├── 制作巴黎街景建筑（低多边形风格）
          ├── 制作咖啡馆内部家具
          ├── 制作 NPC 角色模型
          └── 导出为 glTF 格式

Phase 2   场景搭建（Godot 编辑器）
          ├── 搭建 100m 法式街道
          ├── 搭建咖啡馆室内
          ├── 放置 NPC 和道具
          ├── 设置 POV 相机（第一人称）
          └── 设置 WASD 移动

Phase 3   NPC + 对话
          ├── 编写 NPC 行为脚本（GDScript）
          ├── 实现靠近触发对话
          ├── 集成 LLM API（HTTP 请求）
          ├── 实现键盘输入 + 自由对话
          └── 实现台词气泡 UI

Phase 4   体验打磨
          ├── 昼夜循环 + NPC 作息
          ├── 环境氛围音
          ├── NPC 主动反应（注视/让路）
          └── 性能优化

Phase 5   导出 & 部署
          ├── Web 导出（HTML5/WebGL）
          ├── Desktop 导出（Linux）
          ├── 部署到 Web 服务器
          └── 测试 & 迭代
```
