# 操作逻辑——设计与实施（代入 · 操控 · 交互 · 收益）

**日期：** 2026-10-05
**定位：** 回答三个问题：用户如何通过本项目代入语言环境、如何操控虚拟自己完成一系列交互、如何从中获得收益。含本轮实施范围与验收口径。
**访谈锁定（2026-10-05 两轮）：** 保持第一人称 POV（决策 5/12 不动）；收益 = 世界反馈 + 新居民手册（不加经验条/金钱/等级）；本轮不加新情景、不加引导系统、仅对话交互（环境物件不可交互）。
**锚点规则：** 规则 1 探索即进度、规则 3 失败即成长、规则 4 居民非老师、规则 6 最小 HUD；决策 2 新居民、决策 9 非锁定对话、决策 12 零门槛直接进入、决策 14 NPC 短期记忆。
**姊妹文档：** 巴黎扩展见 `巴黎扩展-实施方案.md`。

---

## 一、代入：怎么"成为"语言环境里的人

### 1.1 身份即设定（零门槛）

- 决策 2：玩家是**刚搬来巴黎的新居民**——NPC 不因你是游客而特殊对待，法语不好是处境不是缺陷。
- 决策 12：启动即街头，无注册/选课/设置；极简提示"**WASD 移动，鼠标看四周**"（系统规则 §五 五分钟体验：30 秒内第一次对话，1 分钟内第一次成功）。
- 代入的叙事载体不是 CG/开场白，而是**环境里的法语**：路名牌、店招牌、菜单板、咖啡馆价目——玩家在"看不懂但想看懂"的状态里自然进入语言环境。

### 1.2 键位提示（借 GTA_SZ quicktips 模式，本轮实施）

- 屏幕底部**单行**极简键位条：`WASD 移动 · E 交谈 · Tab 手册`，开局浮现，全部键位各用过一次后淡出（`city-quicktips.ts`：单行常驻、按状态换文案——本项目更简：一次性教学后退场，服务决策 12 的零门槛）。
- 这是**教学不是 HUD**：淡出后屏幕上不残留任何常驻控件（规则 6）。

### 1.3 环境叙事（本轮轻做，P2-A 深化）

- 路名牌挂"方位词"（借 `city-road-names.ts` 上下文命名：Près du café · 街区），方位表达天然可教。
- 招牌文字分级（`reported/ai-drafted`）在 P2-A 落地；本轮不动。

## 二、操控：第一人称基线的完善

### 2.1 现状盘点（实测）

| 项 | 现状 | 问题 |
|---|---|---|
| 移动 | WASD 即时到速 5.0m/s，停步有减速，**起步无加速** | 手感生硬、起步瞬间速度跳变 |
| 视角 | 鼠标 look ±89°、ESC 两段式释放 | 正常 |
| 设置 | `GameManager.settings` 存 mouse_sensitivity/volume/fullscreen | **存了从不读**：改灵敏度无任何效果 |
| 交互提示 | `interaction_ray.target_found` 是空实现（注释"后续可加准星高亮"） | 玩家不知道谁可以交谈 |
| 暂停 | ESC 两段式 + 对话中交还 dialog_manager（P0 修过） | 正常，不动 |

### 2.2 本轮完善项

1. **移动加减速平滑**：起步加速（`accel = 35 m/s²` 量级，~0.15s 到速）、保留现停步手感；参数 `@export` 暴露便于调。**不加跑/跳/蹲**（本轮范围外）。
2. **设置接线**：鼠标灵敏度从 `GameManager.settings` 读取并生效（`_ready` + 设置变更回调预留）；音量接环境音总线（Ambience 已有两路播放器）。
3. **E 目标提示**：射线命中可对话 NPC 时，准星下方浮现单行 `E · Parler à Marie`（名用法语职业/名字副名牌口径），目标丢失即消失。**仅对 NPC**——环境物件不加提示（决策 19）。

### 2.3 明确不做（访谈范围）

跑动键、蹲伏、环境物件交互（推门/坐下/看菜单交互态）、第三人称切换、手柄支持——均不在本轮；其中跑动/环境交互如后续需要，走设计决策追加流程。

## 三、交互：现有链路的形式化

> 决策 9：对话不是"模式"。以下是唯一合法链路，每步的反馈期望写死，作为断言依据：

```
空闲（NPC 执行原行为：巡走/站立/端咖啡）
  │ 射线命中 + 提示浮现（视觉：E · Parler à Marie）
  │ 玩家按 E
  ▼
发起：is_in_dialog=true，玩家视线锁定 NPC，输入框聚焦
  │ NPC 主动招呼（greeting，或最近 NPC 才招呼——决策 15）
  ▼
多轮往返：玩家键盘输入 → 【思考态：摇摆 + 气泡"…"】→ 回应（点头/注目）
  │ 分支：点单被识别 → serve_order 世界反馈（≤3 杯，杯碟声）
  │ 分支：打字中 WASD 不动；失焦后可走开
  ▼
结束（任一）：① 走开超距自动结束  ② ESC 段1 关输入框 → 段2 结束对话
  ▼
恢复：NPC 恢复原行为（_state_before_talk），鼠标重捕获，玩家可再触发
```

**边界用例（已有断言，本轮只增不减）：** 无后端优雅报错不崩溃；同时多 NPC 只有最近者招呼；暂停菜单在对话中不抢 ESC；对话结束不软锁。

**本轮新增分支——NPC 记忆（决策 14 升级，见 §四.1）。**

## 四、收益：双层结构（兼容规则 6 的核心设计）

> 访谈结论：收益不以数值表达。**第一层活在世界里（即时反馈），第二层活在手册里（积累感）**。借 GTA_SZ story/career 的两条验收思想——**幂等入账**（同一收益不能重复计）与**必须实际发生**（真聊过才记）——不借 XP/金钱/等级本体。

### 4.1 第一层：世界反馈（即时、无 UI）

| 交互完成 | 世界反馈 | 现状 |
|---|---|---|
| 咖啡馆点单成功 | 咖啡真端来 + "Voilà! Bonne journée!" + 杯碟声（≤3 杯防刷） | ✅ 已有（serve_order） |
| 第二次见到同一 NPC | 招呼语变化："Ah, te revoilà !"(你回来啦)——记忆持久在 NPC 实例生命周期内 | 🔧 本轮实施 |
| 完成一次被理解的对话 | NPC 点头注目、气泡收束更利落（回应确认感） | ✅ 已有（acknowledge） |
| 昼夜/作息推进 | 咖啡馆夜间打烊、路灯亮起、NPC 作息切换 | ✅ 已有（P1-4/决策 7） |
| 走到新街段 | 无弹窗无成就——世界本身变宽（路牌/新面孔），手册自动记入足迹 | 🔧 本轮（手册侧） |

### 4.2 第二层：新居民手册（本轮实施）

**打开方式：** `Tab`（暂停外任意时刻），全屏 Control 覆盖层，关闭还原鼠标状态；**不出现在常驻 HUD**（规则 6：屏幕上没有任务列表/分数——手册是玩家**主动翻开**的物件，不是屏幕常驻件）。

**信息架构（三分页）：**

| 页 | 内容 | 数据来源（幂等） |
|---|---|---|
| **足迹 Traces** | 去过的街段（Rue des Rosiers…）、进出过咖啡馆、时间段覆盖（见过清晨/黄昏的街区） | 玩家位置进入区域（zone 进入事件，首次记时间戳，重复进入不重复计） |
| **邻里 Voisins** | 见过的 NPC：名字/职业副名牌/聊过次数/最后一句招呼 | 对话开始事件（首次=认识，此后仅计数+1） |
| **语录 Paroles** | 自己说过且被 NPC 理解采纳的法语句子（如点单成功句） | `conversation_history` 中被 acknowledge/serve_order 确认的玩家句，**按句子去重** |

**设计约束：**
- **不含评分/正确率/等级**——只记"发生过什么"，与规则 3（失败不记录惩罚痕迹）一致；未被理解的句子不进语录（世界没接住，就不是你的语录）。
- **持久化：** `user://handbook.json`，白名单字段校验后读写（借 GTA_SZ `save.ts validateSave`：字段白名单、类型检查、坏文件丢弃回默认不崩溃）。
- **幂等：** 同一区域/同一句/同一 NPC 的重复事件不重复入账（借 story `credit()` 幂等思想）。
- **诚实分级：** 语录条目标 `source: llm-acknowledged`——它是"NPC 听懂了的句子"，**不声称**语法完美（母语者审定缺席，PRODUCT.md Evidence 已声明）。

### 4.3 收益闭环如何回答"从中获得收益"

```
进入世界 → 试着说法语 → 被世界接住（咖啡端来/招呼变化）→ 手册自动留下痕迹
   → 翻开手册看见"我已能完成点单、这条街我认识了三个人" → 更想走进下一条街
   （规则 1：探索即进度——进度是副产品，永远不弹出来要你"领取"）
```

## 五、本轮实施范围（最终清单）

**做：** ① 移动加减速平滑；② settings 灵敏度/音量接线；③ E 目标提示 + quicktips 键位条；④ 新居民手册（三事件钩子 + 三分页 UI + 白名单持久化）；⑤ NPC 二次招呼记忆；⑥ 断言扩展。

**不做：** 新情景、引导/事件系统、环境物件交互、跑跳、第三人称、语音、目标标记、经验/金钱/等级。

**验证口径：**
- `dialog_check` 扩断言（≥50）：手册页可开合、三类钩子各触发 1 条记录、重复事件不重复计、二次招呼文案变化、E 提示浮现/消失、灵敏度设置生效。
- `playthrough_check` 扩闭环：原回放步骤 + 打开手册断言足迹/语录非空 + reload 手册白名单校验通过。
- llvmpipe 截图：手册三分页各一张——**仅位置抽查，不作视觉验收声称**。
- `verify.sh` 维持 10 步（断言并入既有步骤，不加新步）。
- UI 编辑按 impeccable 规程：craft-floor 质量底线先读、完成后 `impeccable detect` 一次。

## 六、诚实边界（本文件的 scope 自陈）

- 本文件声称：设计决策有出处、实现有 headless 断言、UI 有软渲染截图。
