## 一、本次讨论排查发现的问题与解决

### 🔴 问题 1：规则 6 与决策 4 直接矛盾
- **规则 6 说：** NPC 可以理解母语，以目标语回应
- **决策 4 说：** NPC 有自己的语言能力，听不懂就是听不懂
- **解决：规则 6 作废。** 以决策 4 为准。NPC 听不懂就是听不懂，这是真实世界。

### 🟡 问题 2：学习闭环的前置条件
- 学习闭环假设玩家已经有一定基础，但零基础玩家怎么办？
- **解决：当前垂直切片不涉及学习辅助功能。** 聚焦于场景虚拟体验的实现。学习闭环、发音训练、复盘卡片等在后续版本实现。

### 🟡 问题 3：NPC 自适应 vs NPC 语言能力范围的张力
- NPC 自适应（决策 3）说"根据玩家水平调整语言复杂度"
- NPC 语言能力范围（决策 4）说"NPC 有自己的语言能力"
- **解决：两者不矛盾。** NPC 的语言能力是固定的（比如只会说法语），但在这个能力范围内，NPC 会根据玩家的表达水平调整自己的说话方式（对初学者说简单句、放慢语速；对进阶者说复杂句）。这是"能力范围内自适应"。

## 二、所有锁定的设计决策

### 决策 1：纠错时机 → 轻量视觉提示（V2 实现）
> 对话气泡中错误词汇轻微高亮，对话结束后可选复盘卡片。
> **当前版本不实现。**

### 决策 2：玩家身份 → 新居民
> 玩家是刚搬到巴黎的新居民。NPC 有各种态度。
> **影响：** NPC 不会因为你是"游客"就特殊对待，创造更真实的社交环境。

### 决策 3：难度控制 → NPC 自适应（能力范围内）
> NPC 语言能力固定（比如只会法语），但在这个范围内根据玩家水平调整说话方式。

### 决策 4：母语使用 → NPC 有语言能力范围
> NPC 听不懂就是听不懂。不是系统惩罚，是世界本身就这样运转。

### 决策 5：垂直切片标准 → 纯体验优先
> **范围：** POV 移动 + 3D 街区 + 咖啡馆室内 + NPC 对话（键盘）+ 昼夜循环
> **目标：** 验证"世界是否活、探索是否爽"
> **不包含：** 语音输入、学习辅助、发音训练、复盘卡片

## 三、垂直切片设计锁定

### 3.1 场景
- 一条 100m 法式街道 + 1 个可进入咖啡馆
- 街道：石板路、行道树、路灯、长椅、露天座位
- 咖啡馆：柜台、座位区、菜单板、咖啡机

### 3.2 NPC（3个）
1. **咖啡馆服务员**：热情/忙碌，站在柜台后
2. **街上行人**：沿固定路径走动
3. **店主/老人**：坐在长椅上或站在门口

### 3.3 NPC 行为（3种基础）
1. **idle**：站着/坐着，有轻微动作（看手机、喝咖啡）
2. **walk**：沿预设路径走动
3. **interact**：与环境交互（开门、整理柜台）

### 3.4 对话
- **输入方式：** 键盘输入（自由文本）
- **对话引擎：** LLM 驱动（可插拔网关）
- **对话触发：** 靠近 NPC → NPC 主动招呼 → 玩家输入 → NPC 自然回应
- **对话内容：** 取决于 NPC 身份和当前场景（咖啡馆→点单，街头→闲聊）

### 3.5 昼夜循环
- 游戏内时间与现实时间同步
- 光照随时间变化（日出→正午→傍晚→深夜）
- NPC 作息随时间变化（咖啡馆白天开门，晚上关门）

### 3.6 交互深度
- 走进咖啡馆 → 走到柜台 → 服务员招呼 → 自由对话点单 → 咖啡端来
- 可以在咖啡馆里走动、环顾四周
- 街道上可以自由行走、靠近不同 NPC

## 五、V1 完成标准

**玩家体验闭环：**
```
启动应用 → 进入巴黎街头 → WASD 移动探索 → 走进咖啡馆 →
服务员招呼 → 键盘输入对话 → NPC 自由回应 → 咖啡端来 →
走出咖啡馆 → 继续探索 → 天色变化 → NPC 作息变化
```

**验证的核心假设：**
1. POV + 自由探索是否比"场景选择"更能引发探索欲？
2. NPC 的自由对话（LLM驱动）是否比预设脚本更自然？
3. 昼夜循环是否让世界感觉"活"？
4. Web 端 3D 场景是否能达到可接受的帧率？

**技术完成标准：**
- 桌面浏览器稳定 30+ fps
- NPC 对话响应延迟 < 3 秒
- 昼夜循环流畅运行
- 无明显卡顿/崩溃

## 六、第二轮排查追加的决策

### 决策 6：LLM 延迟处理 → NPC 思考动作
> 玩家说完话后，NPC 做思考动作（点头/皱眉/看天），让等待感觉像"在想怎么说"而非"系统在加载"。

### 决策 7：昼夜循环 → 纯实时同步
> 游戏内时间完全跟随现实时间。深夜就是深夜，凌晨就是凌晨。最真实。

### 决策 8：NPC 数量 → 暂不增加
> 维持 3 个 NPC。先实现巴黎街景和咖啡馆，NPC 数量在实现过程中再调整。

### 决策 9：对话结束方式 → 非锁定式对话
> 对话不是一个"模式"。走近→听到/被招呼→可以回应→走开→对话自然结束。
> NPC 说完该说的→自然回到自己的行为。没有"退出对话按钮"。

### 决策 10：咖啡馆氛围 → 视觉+音效
> 暖色调灯光、菜单板、桌椅、咖啡机模型 + 咖啡机声、杯碟声、轻声交谈背景音。

### 决策 11：边界处理 → 自然边界
> 街道尽头设施工围栏/路障/"前方施工请绕行"标志，自然引导而非硬墙。

### 决策 12：开场引入 → 直接进入
> 启动应用直接是巴黎街头画面，极简提示"WASD 移动"。零门槛，不需要注册/选课/设置。

## 八、第三轮排查追加的决策

### 决策 13：对话轮次 → 多轮连续
> 靠近触发后，可以连续聊几轮，直到一方自然结束（NPC说完/玩家走开）。
> 不是"说一句就结束"的单轮触发。

### 决策 14：对话记忆 → NPC 短期记忆
> NPC 记得你刚才聊过（如"啊，你回来了"），但不会追问未完成的话题。
> 每次刷新页面后记忆重置（V1 无持久存储）。

### 决策 15：多人对话 → 只有最近的 NPC 说话
> 如果同时靠近多个 NPC，只有最近的一个主动招呼，另一个保持安静。

### 决策 16：3D 资产来源 → 从长计议
> 实现阶段再决定具体资产获取方式（CC0 / 手搭 / 购买）。

## 十、第四轮排查：技术引擎决策

### 决策 17：开发引擎 → Godot + Blender
> **场景搭建+运行时+Web导出：** Godot 引擎（专业级编辑器、内置物理/动画）
> **3D 资产制作：** Blender（免费开源、功能强大）
>
> **接受的代价：**
> - Web 加载较慢（10-30秒 vs R3F 的 1-3秒）
> - 无法与 React/TypeScript 直接集成
> - GDScript 不是 Web 标准
>
> **获得的能力：**
> - 专业级可视化场景编辑器
> - 内置物理引擎、动画系统、粒子系统
> - 完整的游戏开发工作流
> - 桌面端原生性能
> - 116k+ stars 的活跃社区

## 十五、第八轮：批次 2 接缝方案（2026-10-09）

### 决策 30：两街接缝 → 方案 A「直线展开 + 游戏对接」+ 端头/路面新语义
> 装配器实证为**直线展开**模型（`road_surface` 单块直盒、`street_generator` 无逐段转角），
> 按 ENU 逐段铺设会让接缝断裂。问 A/B/C 后用户选 **A**。
> **方案 A：** 布局只存 `meta.placement = {ref, ref_axis, x, z[, anchor:[v,s]]}`；
> 运行时 `_apply_placement()` 设 `position=(x,0,z)`、`rotation.y=deg_to_rad(my_axis−ref_axis)`
> （轴角差定朝向，接缝在游戏空间直链，**构造误差 = 0**）。参考街（Rosiers）恒等帧。
> **接缝数据（p3_build_joints 实算）：** joint = 罗斯路面端 arc 54.64 → `48.8564991,2.3607108`；
> corridor `{ref:rosiers, z:-89.01}` axisΔ=−180.0°（走廊轴覆盖 126.6°，接缝1 零夹角共线）；
> vosges `{z:-184.6, x:158.23, anchor:[0,374.41]}` axisΔ=−155.0°。接缝自检 0.0041m。
> **端头语义：** `street.ends = [s0端, s1端] ∈ {open|natural|construction}`；
> `street.road_limits = [链起, 链止]`（open 端路面吃此范围：open[0]→`min_s=max(s0−14,rl0)`、
> open[1]→`max_s=rl1` 止于链止；缺省 legacy ±14 外扩逐字节不变）。
> rosiers `["open","natural"]`（natural = 建筑端点 s1+1 花坛护柱，无文字）、
> corridor/vosges `["open","open"]`（跨街走通）。
> **z-fighting：** 走廊 `street.surface_drop=0.004`（接缝2 路面/人行道下沉 4mm 消共面 fight）。
> **投影翻车防护（工具新参，默认关 = 历史字节中性）：** `--span-max 60`（弯折链折返处
> 顶点分投千里 → 超长假楼）、`--max-proj-dist 45`（链未覆盖远段建筑整栋丢弃）；
> 种植网格末位钳 ≤s_max。走廊候选 51→37 栋（剔 14 伪影）。
> **实测：** 三街面数 9,496+19,776+17,400 = 46,672 < 50k（决策 29 总门禁 50k 不动）；
> street_check 156 OK / 0 FAIL（两街新增断言 >50）；接缝1 Δ=0.000m、接缝2 Δ=0.003m；
> playthrough 跨街实走三段全过（joint 走通 / 花坛挡人 / 锚世界走通）。
