# 语宙（LinguaVerse）系统规则设计

**讨论目标：** 最小工作量 × 最高沉浸体验
**版本：** 2.0（排查更新版）
**日期：** 2026-09-05
**状态：** 设计讨论完成

---

## 〇、设计约束与前提

1. **AI 是可插拔的**——规则设计不能依赖任何特定 AI 的能力。
2. **最重要的是沉浸体验**——任何规则如果让玩家感到"我在做练习"，就失败了。
3. **最小工作量**——每个设计决策都要问："这是'必须做'还是'可以没有'？"
4. **Web 端性能天花板**——3D 场景复杂度受浏览器约束。

---

## 一、系统规则设计：六条核心规则

### 规则 1：探索即进度（Explore = Progress）

> 玩家不需要"做任务"来进步。**只要在世界里移动、看见新事物，就在进步。**

| 设计内容 | V1 实现 | V2+ |
|---------|---------|-----|
| 区域解锁 | 玩家走到新区域即可进入 | 更多城市、更大地图 |
| 语言难度 | 不同区域自然不同（咖啡馆 vs 街头） | 更精细的难度梯度 |
| 隐性进度 | 记录去过哪、跟谁聊过 | 完整的学习进度追踪 |

**工作量：** V1 极低——世界地图 + 玩家位置追踪 + 区域标注。

---

### 规则 2：情景即课本（Scenario = Lesson）

> 世界里自发产生的每一个情景，就是一堂自然课。

| 情景类型 | V1 | V2+ |
|---------|-----|-----|
| 咖啡馆点单 | ✅ 核心场景 | 更多餐饮情景 |
| 街头问路 | ❌ | ✅ |
| 邻居打招呼 | ❌ | ✅ |
| 菜市场购物 | ❌ | ✅ |
| 电话预约 | ❌ | ✅ |
| 社区会议 | ❌ | ✅ |

**V1 范围：** 只做「咖啡馆点单」——场景最小、情景最自然、闭环最短。

---

### 规则 3：失败即成长（Failure = Growth）

> 世界不惩罚失败。沟通失败本身就是最有效的学习。

| 情况 | V1 处理 | V2+ |
|------|---------|-----|
| 语法错误 | NPC 可能困惑/追问（自然反应） | 对话气泡高亮错误词 |
| 完全听不懂 | NPC 换一种方式说或放弃对话 | NPC 更丰富的降级策略 |
| 用母语说话 | NPC 有自己的语言能力，听不懂就是听不懂 | 部分 NPC 可能懂一些 |
| 转身离开 | NPC 不追究，继续自己的事 | 不变 |

**V1 关键：** 没有"Game Over"，没有扣分，没有惩罚。所有"失败"被世界消化为自然反应。

---

### 规则 4：NPC 不是老师，是居民（NPCs = Residents, Not Teachers）

> NPC 的唯一目的是过自己的生活。玩家的互动是"闯入他们的生活"。

| NPC 维度 | V1 | V2+ |
|---------|-----|-----|
| 身份 | 每个 NPC 有名字、职业、性格 | 更丰富的身份系统 |
| 日常 | 基础作息（开门/关门/走动） | 完整作息轨迹 |
| 情绪 | 基础反应（被打扰→不高兴） | 更丰富的情绪系统 |
| 记忆 | 记得玩家上次来过 | 完整的对话历史记忆 |
| 边界 | 不主动教学 | 不变 |

**NPC 对话行为（V1 三种模式）：**
1. **主动招呼**（靠近/进门时）："Bonjour! Vous désirez?"
2. **被动回应**（玩家开口时）：根据内容自然回话。
3. **基础反应**（被碰撞/盯着看时）：轻微反应。

> **NPC 绝不说"让我教你……"或"你应该说……"。**

---

### 规则 5：时间是活的（Living Time）

> 世界有自己的时间。同一地点在不同时间，是完全不同的世界。

| 时段 | V1 咖啡馆 | V1 街道 |
|------|----------|---------|
| 白天 | 开门营业，服务员在 | 有行人走动 |
| 夜晚 | 关门/打烊 | 空旷，少数夜归人 |

**V1 实现：** 游戏内时间与现实时间同步，光照随时间变化，NPC 作息随之变化。

---

### 规则 6：最小 HUD，最大世界（Minimal HUD, Maximum World）

> 屏幕上没有经验条、没有任务列表、没有分数。

| 传统游戏 HUD | V1 语宙 |
|-------------|---------|
| 经验值条 | 无 |
| 任务列表 | 无 |
| 分数/等级 | 无 |
| 小地图 | 可选（极简区域地图） |
| 对话框 | 保留（台词气泡 + 键盘输入） |

## 二、已作废的规则

### ~~规则 6：语言是双向的（Bilingual Bridge）~~ 【已作废】

> 原设计：玩家的母语是桥梁，NPC 可以理解母语并以目标语回应。
>
> **作废原因：** 与"NPC 有自己的语言能力范围"（决策 4）直接矛盾。

## 三、学习闭环设计（V2 实现）

> **当前版本（V1）不实现学习闭环。** 以下设计留待 V2。

### V2 学习闭环：「沉浸→接触→内化→输出」

```
① 沉浸（Immersion）
│ 进入世界，感受环境，无目的漫游
│ 语言输入：环境音、路牌、广告、NPC 闲聊
│ 目标：建立"语感"和"场景-语言"关联
│
② 接触（Encounter）
│ 遇到情景，触发交互意图
│ 语言输入：NPC 对话、场景文字、物品名称
│ 目标：理解当前情景的语言要素
│
③ 内化（Internalization）
│ 尝试开口，犯错，NPC 自然回应
│ 语言输出：尝试用目标语表达
│ 目标：通过实践+自然反馈，将输入转化为能力
│
④ 输出（Expression）
│ 成功完成一次沟通（买到咖啡、问对了路）
│ 语言输出：完整的对话+行为达成
│ 目标：获得成就感，建立自信
│
→ 循环回到 ①：带着新能力，探索更深的世界
```

### V2 闭环如何"不感觉像学习"
1. 没有"测试"——你不是在考试，你是在生活。
2. 没有"评分"——NPC 不会给你打分，只会自然反应。
3. 进度是副产品——你探索得越多，能去的地方越多。
4. 成就感来自世界反馈——买到咖啡，咖啡真的端到你面前。

## 四、发音训练闭环（V2 实现）

> **当前版本（V1）不实现发音训练。** 以下设计留待 V2。

### V2 核心理念：发音不是"练出来的"，是"被听出来的"

> 传统的发音训练：录音→分析→纠正→再录（枯燥）
> 语宙的发音训练：你说→NPC 听懂/听不懂→自然反应→你调整（真实）

### V2 发音训练的自然闭环

```
玩家尝试开口说话
        │
        ▼
   NPC 的"理解程度"反应
   │
   │  说得好 → NPC 完全理解 → 对话继续
   │  说得一般 → NPC 需要确认 → "Pardon?"
   │  说得差 → NPC 听不懂 → 换方式问
   │
        ▼
   玩家调整发音，重新尝试
        ▼
   NPC 反馈变化（听懂了！）
        ▼
   成就感：我的发音进步了！
```

### V2 技术实现
- **STT 置信度**作为"理解程度"的代理指标（低复杂度）
- **NPC 反应多样性**：基于置信度，NPC 回应三种状态
- **关键洞察：** 不需要真的分析发音，只需让 NPC 的反应"看起来像听不懂"

### V2 发音反馈呈现
| 时机 | 方式 | 打断沉浸？ |
|------|------|-----------|
| 对话中 | NPC 的反应（皱眉/重述） | ❌ 不打断 |
| 对话后 | 复盘卡片：发音模糊词 + 标准对比 | ✅ 对话已结束 |
| 主动请求 | NPC 自然示范 | ❌ 自然请求 |

## 五、五分钟体验设计（V1 目标）

### 玩家第一次打开语宙，前五分钟：

```
0:00  启动应用
      → 直接进入巴黎街头画面
      → 背景音：鸟鸣、远处人声

0:10  屏幕提示："WASD 移动，鼠标看四周"
      → 玩家移动，看到法式街道
      → 看到远处有咖啡馆

0:30  走近咖啡馆
      → 门自动打开
      → 进入，环境音切换为室内
      → 看到服务员在柜台后面

0:45  走近柜台
      → 服务员抬头："Bonjour! Vous désirez?"
      → 屏幕下方出现对话输入框

1:00  玩家输入（键盘）："un café, s'il vous plaît"
      → 服务员回应（LLM 自由生成）
      → 第一次自然法语对话

1:30  咖啡端来
      → 服务员："Voilà! Bonne journée!"
      → 完成一次完整对话

2:00  走出咖啡馆，环顾四周
      → 看到窗外有人走过
      → 自然产生"想去那边看看"的欲望

3:00  继续探索街道
      → 遇到其他 NPC
      → 靠近触发不同对话

4:00  走到街角
      → 看到街景变化
      → 每个角落都有可能产生对话

5:00  玩家已经"活"在了这个街区里
```

### 五分钟设计三原则
1. **零门槛**：不需要注册/选课/设置难度。
2. **第一次对话在 30 秒内**：进咖啡馆→被招呼→开口说话。
3. **第一次成功在 1 分钟内**：完成一次对话，买到咖啡。

## 六、NPC 设计（V1）

### 三个核心 NPC

| NPC | 身份 | 位置 | 性格 | 语言能力 |
|-----|------|------|------|---------|
| 服务员 | 咖啡馆服务员 | 咖啡馆柜台 | 热情/忙碌 | 只会法语 |
| 行人 | 街上路人 | 沿路径走动 | 中性 | 只会法语 |
| 老人 | 街角长椅上的老人 | 街角长椅 | 友善 | 只会法语 |

### NPC 行为（V1 三种基础）
1. **idle**：站着/坐着，有轻微动作
2. **walk**：沿预设路径走动
3. **interact**：与环境交互（开门、整理）

### NPC 对话 Prompt 模板（V1）

```
你是 {名字}，一个巴黎 {职业}。
你的性格是 {性格}。
你现在在 {位置}，当前时间是 {时间}。
你会说法语，但不会英语或其他语言。
玩家是一个刚搬到巴黎的新居民，法语不太好。

你的说话方式：
- 自然、口语化
- 根据玩家的表达水平调整复杂度
- 如果听不懂就说"Je ne comprends pas"
- 不要主动教语法，你只是在过自己的生活
```
